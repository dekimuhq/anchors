# `@dekimuhq/guard-detect`

Zero-dependency deterministic detection engine for prompt-injection and jailbreak patterns.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/guard

## Install

```bash
npm install @dekimuhq/guard-detect
```

Requires Node ≥24.6.
