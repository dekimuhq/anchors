# `@dekimuhq/guard-profiles`

Profile validators + body types for Anchored Guard Verdicts (AGR) v1.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/guard

## Install

```bash
npm install @dekimuhq/guard-profiles
```

Requires Node ≥24.6.
