# `@dekimuhq/guard`

Anchored Guard Verdicts (AGR) v1 — verify (default) + issue (./issue). Input-screening provenance, not safety.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/guard

## Install

```bash
npm install @dekimuhq/guard
```

Requires Node ≥24.6.
