# `@dekimuhq/atokr-profiles`

[![Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Regulation profile validators for ATokR v1 — 5 profiles: `tokenization.gdpr.art32`, `tokenization.gdpr.art4_5`, `tokenization.pci.dss_v4`, `tokenization.eudi.wallet_arf`, `tokenization.sector.health`.

## Install

```bash
npm install @dekimuhq/atokr-profiles
```

## Usage

See the [ATokR spec](../../meta/FAMILY-CONSISTENCY.md) for the full profile definitions.
