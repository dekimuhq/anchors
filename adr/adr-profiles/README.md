# `@dekimuhq/adr-profiles`

[![Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

Regulation profile validators for ADR v1 — 5 profiles: `aiact.art26.deployer`, `aiact.art14.oversight`, `agentops.scoped-delegation`, `gdpr.art28.processor`, `corporate.officer`.

## Install

```bash
npm install @dekimuhq/adr-profiles
```

## Usage

See the [ADR spec](../../meta/FAMILY-CONSISTENCY.md) for the full profile definitions.
