# `@dekimuhq/aar`

Anchored Attestation Receipts (AAR) v1 — verify (default) + issue (./issue) for eIDAS QTSP issuance attestation receipts.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/aar

## Install

```bash
npm install @dekimuhq/aar
```

Requires Node ≥24.6.
