# `@dekimuhq/aar-profiles`

Regulation profile validators for AAR v1: eidas.qes, eidas.qeseal, eidas.qts, eidas.qereg, eidas.qcert.natural, eidas.qcert.legal, eidas.qwallet, eidas.qattest.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/aar

## Install

```bash
npm install @dekimuhq/aar-profiles
```

Requires Node ≥24.6.
