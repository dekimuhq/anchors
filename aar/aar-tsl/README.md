# `@dekimuhq/aar-tsl`

EU Trust List snapshot tooling for Anchored Attestation Receipts (AAR)

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/aar

## Install

```bash
npm install @dekimuhq/aar-tsl
```

Requires Node ≥24.6.
