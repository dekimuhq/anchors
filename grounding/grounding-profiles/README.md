# @dekimuhq/grounding-profiles

Body types and profile validator for Anchored Grounding Receipts (`ar.grounding.v1`, AGrR chip 18). Implements `validateGroundingRag` — stateless shape + internal-coherence check including recomputed `coverage`, `grounded_count`, and per-citation `support↔score` boundary. **Provenance, not truth**: binding verified against named source commits; support score is method-attributed (`lexical_overlap`), advisory.
