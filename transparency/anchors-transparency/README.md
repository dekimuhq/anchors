# `@dekimuhq/anchors-transparency`

Verifier-side transparency-log primitives for the Anchored Receipts family (leaf hashing, inclusion/consistency proofs, C2SP checkpoints). node:crypto only.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

## Install

```bash
npm install @dekimuhq/anchors-transparency
```

Requires Node ≥24.6.
