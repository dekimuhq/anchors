Regulation profile validators for **AIR (Anchored Impact-Assessment Receipts) v1** (`ar.impact.v1`).

- **Licence:** Apache 2.0.
- **Version:** 0.6.1
- **Status:** Shipped — published.
- **Spec:** https://github.com/dekimuhq/anchors-spec/tree/main/air.
- **Pairs with:** [`@dekimuhq/air`](../air) — the consolidated family package: verify side at the root export, mint side at its `./issue` subpath.

## Install

```bash
npm install @dekimuhq/air-profiles
```

Requires Node ≥24.6 (built-in Ed25519 in `node:crypto`). Published under the `@dekimuhq` npm scope.
