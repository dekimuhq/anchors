# `@dekimuhq/atr`

Anchored Transfer Receipts (ATR) v1 — verify (default) + issue (./issue) for GDPR Chapter V cross-border data transfer receipts.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/atr

## Install

```bash
npm install @dekimuhq/atr
```

Requires Node ≥24.6.
