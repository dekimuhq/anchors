# `@dekimuhq/atr-profiles`

Regulation profile validators for ATR v1: gdpr.art45.adequacy, gdpr.art46.scc, gdpr.art46.bcr, gdpr.art46.idta, gdpr.art47.bcr_authorised, gdpr.art49.derogation, gdpr.dpf, schremsii.tia.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/atr

## Install

```bash
npm install @dekimuhq/atr-profiles
```

Requires Node ≥24.6.
