# `@dekimuhq/redaction-profiles`

APIIR (Anchored PII-Redaction Receipts) profile validators — redaction.prompt.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

## Install

```bash
npm install @dekimuhq/redaction-profiles
```

Requires Node ≥24.6.
