# `@dekimuhq/redaction`

Anchored PII-Redaction Receipts (APIIR) v1 — verify (default) + issue (./issue). Redaction provenance, not a PII-free guarantee.

Part of the [Anchored Receipts](https://github.com/dekimuhq/anchors) reference implementation.

Spec: https://github.com/dekimuhq/anchors-spec/tree/main/redaction

## Install

```bash
npm install @dekimuhq/redaction
```

Requires Node ≥24.6.
